Seules les personnes de cette liste peuvent se connecter. Première connexion : adresse + code d'activation (à leur remettre) + mot de passe choisi. Le code ne sert qu'une fois ; « Réinitialiser l'accès » en donne un nouveau (mot de passe oublié). Un formateur voit les outils des formations de ses classes ; direction, vie scolaire, secrétariat, coordination et responsable pédagogique voient toutes les formations. ★ = référent·e de la classe.
